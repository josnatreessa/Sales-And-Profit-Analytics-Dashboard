# 📊 Executive Sales & Profit Analytics Dashboard (Excel)

![Dashboard Overview](Sales%20Dashboard%20screenshot.png)

An interactive, executive-level Excel dashboard designed to analyze retail sales performance, profit margins, order distributions, and top-performing product categories.

---

## 📌 Project Overview
This project provides an end-to-end sales analytics solution built in Microsoft Excel. The dashboard enables business stakeholders to evaluate profit margins, track sales trends over time, analyze regional performance, and identify top-revenue products through dynamic filtering.

---

## 🔑 Key Metrics & Insights
* **Total Revenue:** ₹23,26,534.35
* **Total Profit:** ₹2,92,296.81
* **Profit Margin:** 12.56%
* **Total Orders Processed:** 10,194 Orders

---

## 🚀 Key Dashboard Features
* **Interactive Slicers:** Dynamic filtering across **Region** (Central, East, South, West), **Category** (Furniture, Office Supplies, Technology), and **Ship Mode** (First Class, Same Day, Second Class, Standard Class).
* **Trend Analysis:** Line chart visualizing multi-year sales progression and trajectory.
* **Product Performance:** Detailed breakdown of the **Top 10 Products by Sales** with optimized horizontal bar layout.
* **Category & Regional Breakdown:** Comparative visual assessment of profit margins across merchandise categories and geographic regions.

---

## 🛠️ Tools & Technologies
* **Tool:** Microsoft Excel
* **Features Used:** Pivot Tables, Pivot Charts, Slicers, Data Cleaning, Conditional Formatting, Custom Formatting, KPI Card Design.
